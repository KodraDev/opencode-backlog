# Upstream attribution

KodraDev's `kodradev-opencode-backlog` is based on
[sachahjkl/opencode-backlog](https://github.com/sachahjkl/opencode-backlog),
cloned at commit `3c38cd5` (upstream package version `0.2.3`).

The original MIT license and copyright notice are preserved in `LICENSE`.
The upstream Git history is preserved. The `upstream` remote points to the
original repository; `origin` points to https://github.com/KodraDev/opencode-backlog.
Do not push this variant to upstream.

Local changes introduce SQLite storage, automatic session isolation, bounded
output, and a server-backed sidebar. This is not an official upstream release.
